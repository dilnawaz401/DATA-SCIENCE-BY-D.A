## Deep Learning (DL)

Deep Learning is a subset of Machine Learning that uses multi-layered neural networks to learn complex patterns from data.

1. Simple Definition

Deep Learning teaches computers to learn complex patterns using neural networks inspired by the human brain.

2. AI vs ML vs DL
Artificial Intelligence (AI)
          |
          └── Machine Learning (ML)
                    |
                    └── Deep Learning (DL)

AI: Makes machines perform intelligent tasks.

ML: Learns patterns from data.

DL: Uses deep neural networks to learn complex patterns.

3. ANN — Artificial Neural Network

An ANN is a network of connected artificial neurons that process information.

Input Layer

Receives input features

Hidden Layer(s)

Learns patterns using weights and activation functions

Output Layer

Produces the prediction

The main parts are:

Weights: determine how strongly inputs influence a neuron.

Bias: an additional adjustable value.

Activation function: transforms a neuron's calculated value.

Layers: organize the flow of information through the network.

6. Single-Layer vs Multilayer Perceptron

Single-layer perceptron: has no hidden layer and can learn only linearly separable classification problems.

Multilayer perceptron (MLP): has one or more hidden layers and can learn more complex, nonlinear relationships when suitable activation functions are used.

Easy memory: One layer = simple boundary; multiple layers = more complex patterns.

1. What is sequential data?

Sequential data is data where the order of elements matters.

Examples from the lecture's topic:

Text: words appear in a particular order.

Time series: today's temperature depends partly on patterns over time.

Speech: sounds arrive in sequence.

Stock prices: values are recorded over time.

Consider these sentences:

“The food is good.”

“The food is not good.”

The word not changes the meaning. A model that ignores word order may struggle to distinguish them.

2. What is RNN?

RNN = Recurrent Neural Network.

An RNN is a type of neural network designed to process sequential data. It carries information from earlier time steps into later ones through a hidden state.

Word 1          Word 2          Word 3
   ↓               ↓               ↓
 RNN at t1  →   RNN at t2  →   RNN at t3
   ↓               ↓               ↓
 Hidden state → Hidden state → Hidden state

The hidden state acts like a small memory of what the network has processed so far.

3. Example: Sentiment Analysis

Suppose the input is:

“The food is not good.”

The RNN reads the words in sequence:

"The" → "food" → "is" → "not" → "good"
                                      ↓
                            Predict sentiment
                                      ↓
                                  Negative

As it reads each word, it updates its hidden state. This allows it to use earlier words when interpreting later ones.

5. Backpropagation in RNN: BPTT

For an RNN, backpropagation through time (BPTT) is used to train the network across sequence time steps.

Time 1 → Time 2 → Time 3 → Time 4
   ↑        ↑        ↑        ↑
   └────────┴────────┴────────┘
       Gradients flow backward

The model uses errors from its outputs to calculate how its shared weights should be updated.

1. Vanishing Gradient Problem

During backpropagation through a long sequence, gradients may become extremely small.

As a result, the model has difficulty learning relationships between words or events that are far apart.

Example

Consider this sentence:

“I grew up in India, and after living abroad for many years, I still speak fluent Hindi.”

To interpret “Hindi,” the model may need to remember information from earlier in the sentence.

A simple RNN may struggle to preserve useful information across many time steps.

Long Sequence
      ↓
Backpropagation Through Time
      ↓
Gradients become very small
      ↓
Early time steps learn very slowly
      ↓
Difficulty learning long-term dependencies
2. Why do gradients vanish?

5. How LSTM Helps

LSTM uses gates to control which information to keep, remove, or output.

Forget gate: decides what information to discard.

Input gate: decides what new information to store.

Output gate: decides what information to output.

GRU uses update and reset gates to manage information in a simpler structure.
