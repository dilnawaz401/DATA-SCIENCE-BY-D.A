## 📊 Regression Metrics

Regression is used when the output is a number.

Example: Predicting house prices.

Suppose actual prices are:

Actual:     100   200   300   400
Predicted:   90   210   280   420
1. MAE — Mean Absolute Error

Meaning: MAE tells us the average amount by which our prediction is wrong.

First find the errors:

Actual      Predicted      Error
100            90            10
200           210            10
300           280            20
400           420            20

Average error:

MAE = (10 + 10 + 20 + 20) / 4
    = 15

👉 MAE = Average absolute error

Easy line:
MAE tells "On average, how much am I wrong?"

Lower MAE = Better model

2. MSE — Mean Squared Error

Meaning: MSE takes the errors, squares them, and then calculates their average.

Errors:       10, 10, 20, 20

Squares:     100, 100, 400, 400
MSE = (100 + 100 + 400 + 400) / 4
    = 250

👉 MSE = Average of squared errors

Why square the error?
Large errors get a much bigger penalty.

For example:

Error = 2   → 2² = 4
Error = 10  → 10² = 100

Easy line:
MSE gives more punishment to large errors.

Lower MSE = Better model

3. RMSE — Root Mean Squared Error

Meaning: RMSE is the square root of MSE.

RMSE = √MSE

     = √250
     ≈ 15.81

👉 RMSE = √MSE

The biggest advantage is that RMSE is in the same unit as the original output.

For example, if house price is measured in ₹lakhs, RMSE is also in ₹lakhs.

Easy line:
RMSE tells the typical prediction error in the original unit.

Lower RMSE = Better model

4. R² Score — R-Squared

Meaning: R² tells us how well the model explains the variation in the data.

Generally:

R² = 1        → Perfect model
R² close to 1 → Very good
R² = 0        → Model explains very little
R² < 0        → Very poor model

Example:

R² = 0.80

→ Model explains about 80% of the
  variation in the target data.

Easy line:
R² tells "How well does my model explain the data?"

Higher R² = Generally better




## Overfitting and Underfitting

These are two common problems in Machine Learning models.

1. Underfitting

Definition: Underfitting happens when the model is too simple and cannot learn the important patterns from the training data.

Training Data
     ↓
  Too Simple
     ↓
Misses Important Patterns
     ↓
Poor Prediction

Example:
Trying to predict house prices using only house size, while ignoring location, rooms, age, etc.

Symptoms:

Training accuracy → Low
Testing accuracy → Low

👉 Easy line: Underfitting = Model learns too little.

2. Overfitting

Definition: Overfitting happens when the model learns the training data too well, including noise and unnecessary details.

Training Data
     ↓
  Too Complex
     ↓
Memorizes Data + Noise
     ↓
Poor New Data Prediction

Example:
A model memorizes the exact prices of houses in the training dataset but performs badly on new houses.

Symptoms:

Training accuracy → Very High
Testing accuracy → Low

👉 Easy line: Overfitting = Model learns too much.

## Ridge, Lasso and Elastic Net Regression

These are regularization techniques used in regression to reduce overfitting and improve model performance.

1. Ridge Regression

Ridge Regression adds a penalty based on the square of coefficients.

Formula:

$$ Loss = MSE + \lambda\sum b_i^2 $$
It makes coefficients smaller.
Usually does not make coefficients exactly zero.
Useful when many features are important.

Easy line:
👉 Ridge = Shrinks coefficients

2. Lasso Regression

Lasso Regression adds a penalty based on the absolute value of coefficients.

Formula:

$$ Loss = MSE + \lambda\sum |b_i| $$
Can make some coefficients exactly zero.
Therefore, it can perform feature selection.
Useful when some features are unnecessary.

Easy line:
👉 Lasso = Removes unnecessary features

3. Elastic Net Regression

Elastic Net combines both Ridge + Lasso penalties.

Formula:

$$ Loss = MSE + \lambda_1\sum|b_i| + \lambda_2\sum b_i^2 $$
Combines feature selection from Lasso.
Combines coefficient shrinking from Ridge.
Useful when there are many features and some are correlated.

Easy line:
👉 Elastic Net = Ridge + Lasso

Quick Comparison
Method	Penalty	Main Use
Ridge	\(b^2\)	Shrinks coefficients
Lasso	(b)
Elastic Net	Both	Shrinking + feature selection

## SVM (Support Vector Machine)

SVM is a supervised machine learning algorithm mainly used for classification. It can also be used for regression (SVR).

Simple Definition

SVM finds the best boundary (hyperplane) that separates different classes of data.

Example: Pass / Fail

Suppose we have students based on study hours and marks:

Marks
  |
  |       ● Pass       ● Pass
  |    ● Pass
  |
  |-------------------------  ← Best Boundary
  |   × Fail       × Fail
  |      × Fail
  |
  +--------------------------→ Study Hours

The line separating the two groups is called the decision boundary / hyperplane.

What is Margin?

SVM doesn't just find any boundary. It tries to find the boundary with the maximum distance from the nearest points of both classes.

Class A       Margin       Class B

   ●            |            ×
      ●         |         ×
         ●      |      ×
                |
          Decision
          Boundary

The closest points are called Support Vectors.

Important Terms

1. Hyperplane
The boundary that separates classes.

2. Support Vectors
Data points closest to the boundary.

3. Margin
Distance between the boundary and the nearest support vectors.

4. Kernel
Used when data cannot be separated easily using a straight line.

Common kernels:

Linear
Polynomial
RBF
Sigmoid

Simple Definition

Naive Bayes predicts a class using probability and Bayes' theorem.

Example: Spam Detection 📧

"Congratulations! You won a free prize."

Naive Bayes checks the words and calculates:

Email
  ↓
Words / Features
  ↓
Naive Bayes
  ↓
Probability
  ↓
Spam or Not Spam

For example:

P(Spam | Email)     = 90%
P(Not Spam | Email) = 10%

Therefore → Spam
Why "Naive"?

It is called Naive because it assumes that features are independent of each other.

For example:

"free" + "prize" + "winner"
       ↓
Naive Bayes
       ↓
Assumes each word independently contributes
to the probability of Spam
Bayes' Theorem
$$ P(A|B)=P(B/A)PA / P(B)
	​


Where:

P(A|B) → Probability of A when B is known
P(B|A) → Probability of B when A is true
P(A) → Prior probability
P(B) → Evidence
Common Uses

😊 Sentiment analysis
📰 News classification

## KNN (K-Nearest Neighbors)

KNN is a supervised machine learning algorithm used for classification and regression.

Simple Definition

KNN predicts a new data point by looking at the K nearest data points around it.

Example: Classifying a Fruit 🍎🍊

Suppose we have known fruits:

        🍎 Apple
    🍎

             ?  ← New Fruit

        🍊
            🍊 Orange

KNN checks the nearest fruits to ?.

If K = 3:

Nearest 3 fruits:
🍎 Apple
🍎 Apple
🍊 Orange

Apple = 2
Orange = 1

Therefore → Apple
How KNN Works
New Data
   ↓
Choose K
   ↓
Calculate Distance
   ↓
Find K Nearest Neighbors
   ↓
Majority Vote
   ↓
Prediction
What is K?

K = Number of nearest neighbors considered.

Example:

K = 3 → Look at 3 nearest points
K = 5 → Look at 5 nearest points

For classification, the class with the majority vote is selected.

Distance

KNN commonly uses Euclidean Distance:

$$ d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} $$

It measures how close two data points are.

KNN for Regression

Instead of voting, KNN can take the average value of nearby points.

KNN
 ├── Classification → Majority Vote
 └── Regression      → Average Value
Advantages
Simple and easy to understand
No complicated training process
Works for classification and regression
Disadvantages
Can be slow with large datasets
Sensitive to feature scaling
Choosing the right K is important
🧠 Easy Memory Trick

KNN = Look at nearest neighbors and decide.

K = Number of Neighbors
NN = Nearest Neighbors





## KD-Tree and Ball Tree

Both KD-Tree and Ball Tree are data structures used to make KNN (K-Nearest Neighbors) searches faster.

Instead of comparing a new point with every data point, they organize the data so that nearby points can be found more efficiently.

1. KD-Tree

KD-Tree = K-Dimensional Tree

It divides data using axis-based splits.

Example with 2 features:

        All Data
           ↓
      Split by X
       /       \
      /         \
 Split by Y   Split by Y
    ↓             ↓
 Data          Data

It works well when:

Number of dimensions is relatively low
Data is reasonably suitable for axis-based partitioning

Easy line:
👉 KD-Tree = Divides data using dimensions/axes.

2. Ball Tree

Ball Tree divides data into balls (regions) around groups of points.

        All Data
           ↓
      Create Balls
       /         \
   Ball 1       Ball 2
   ● ● ●        ● ● ●

It is often useful for:

Higher-dimensional data
Distance-based searches
Data where KD-Tree is less effective

Easy line:
👉 Ball Tree = Divides data into spherical regions.

KD-Tree vs Ball Tree
KD-Tree	Ball Tree
Axis-based splitting	Ball/region-based splitting
Divides by dimensions	Groups points by distance
Good for lower dimensions	Can work better with higher dimensions
Used for KNN search	Used for KNN search
KNN Connection
                KNN
                 ↓
       Need nearest neighbors
                 ↓
        ┌────────┴────────┐
        ↓                 ↓

## Decision Tree 🌳

Decision Tree is a supervised machine learning algorithm used for both classification and regression.

Simple Definition

Decision Tree makes predictions by asking a series of questions and following branches until it reaches an answer.

Example: Play or Not Play 🎾
             Weather?
            /        \
         Sunny       Rainy
          /            \
      Humidity?       Play?
      /      \        /   \
   High     Normal   No    Yes
    ↓          ↓
    No        Yes

The tree asks questions step-by-step and finally gives a prediction.

Important Terms

1. Root Node
The first/main question.

2. Decision Node
A node where the data is split based on a condition.

3. Branch
The path followed after a decision.

4. Leaf Node
The final answer/prediction.

        Root Node
            ↓
      Decision Node
        /       \
    Branch     Branch
      ↓           ↓
   Leaf         Leaf
 (Answer)      (Answer)
How Decision Tree Works
Training Data
     ↓
Choose Best Feature
     ↓
Split Data
     ↓
Ask Questions
     ↓
Repeat Splitting
     ↓
Leaf Node
     ↓
Prediction
Classification vs Regression
Decision Tree	Output
Classification Tree	Category/Class
Regression Tree	Numerical value

Example:

Classification → Spam / Not Spam
Regression     → House Price
How does it choose the best split?

Common measures are:

Gini Impurity
Entropy / Information Gain
Advantages
Easy to understand
Easy to visualize
Works with classification and regression
Does not require feature scaling
Disadvantage
A very deep tree can overfit the training data.

## Random Forest 🌲🌲🌲

Random Forest is a supervised machine learning algorithm that combines many Decision Trees to make a better prediction.

Simple Definition

Random Forest = Collection of many Decision Trees working together.

How It Works

Suppose we have 5 Decision Trees:

                 Random Forest
                      ↓
       ┌──────┬──────┼──────┬──────┐
       ↓      ↓      ↓      ↓      ↓
     Tree1  Tree2  Tree3  Tree4  Tree5
       ↓      ↓      ↓      ↓      ↓
      Yes    Yes     No    Yes    Yes
       └──────┴──────┼──────┴──────┘
                      ↓
                 Majority Vote
                      ↓
                     YES

For classification, the trees use majority voting.

For regression, the predictions from the trees are generally averaged.

Example

Predict whether a customer will buy a product:

Tree 1 → Buy
Tree 2 → Buy
Tree 3 → Not Buy
Tree 4 → Buy
Tree 5 → Buy

Majority → BUY
Why "Random"?

Random Forest introduces randomness in:

The training samples used for each tree
The features considered when splitting nodes

This makes the trees different from each other and usually helps reduce overfitting compared with a single deep decision tree.

Decision Tree vs Random Forest
Decision Tree	Random Forest
One tree	Many trees
Can overfit easily	Usually less overfitting
Simple	More powerful
One prediction	Combines many predictions

     ↓
Create Random Samples
     ↓
Build Many Decision Trees
     ↓
Each Tree Makes Prediction
     ↓
Voting / Averaging
     ↓
Final Prediction

Decision Tree = One Tree 🌳

##  AdaBoost

AdaBoost = Adaptive Boosting

It is a supervised machine learning ensemble algorithm that combines several weak learners to create a stronger model.

Simple Definition

AdaBoost = Learn from mistakes and improve step-by-step.

How AdaBoost Works

Suppose we use small Decision Trees as weak learners:

Training Data
      ↓
Weak Learner 1
      ↓
Find Wrong Predictions
      ↓
Give More Weight to Wrong Data
      ↓
Weak Learner 2
      ↓
Again Focus on Mistakes
      ↓
Weak Learner 3
      ↓
Combine All Learners
      ↓
Final Prediction
Simple Example

Imagine 5 students' data:

Model 1 → Gets 2 examples wrong
             ↓
      Give those examples
        more importance
             ↓
Model 2 → Focuses on them
             ↓
      Again find mistakes
             ↓
Model 3 → Improves prediction

So, AdaBoost doesn't treat every training example equally throughout the process. It increasingly focuses on examples that previous learners classified incorrectly.

Why "Adaptive"?

It is called Adaptive because the algorithm adapts to previous mistakes by changing the importance (weights) of training examples.

AdaBoost vs Random Forest
Random Forest	AdaBoost

Bagging approach	Boosting approach

## K-Means Clustering

K-Means is an unsupervised learning algorithm used for clustering.

Simple Definition

K-Means divides data into K groups (clusters) based on similarity.

Here, K = number of clusters we want.

Example

Suppose we have customer data:

Customer Data
     ↓
   K-Means
     ↓
 ┌───────┬───────┬───────┐
 │Group 1│Group 2│Group 3│
 └───────┴───────┴───────┘

For example:

Group 1: Low-spending customers
Group 2: Medium-spending customers
Group 3: High-spending customers
How K-Means Works
1. Choose K
      ↓
2. Select K random centroids
      ↓
3. Assign each data point
   to nearest centroid
      ↓
4. Calculate new centroid
      ↓
5. Repeat steps 3 & 4
      ↓
6. Stop when clusters don't change
Important Terms

K → Number of clusters

Centroid → Center point of a cluster

Cluster → Group of similar data points

Distance → Measures how close a data point is to a centroid

Usually, Euclidean distance is used:

$$ d=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2} $$
Simple Example

If:

K = 2

The algorithm creates:

        Data
          ↓
       K = 2
          ↓
   ┌─────────────┐
   ↓             ↓
Cluster 1     Cluster 2
   ↓             ↓
Similar       Similar
Points        Points
Advantages
Simple and easy to understand
Fast for large datasets
Useful for customer segmentation
Easy to implement
Disadvantages
Need to choose K beforehand
Sensitive to outliers
Different starting centroids can give different results
Works best when clusters are reasonably well separated
🧠 Easy Memory Trick

K-Means = Choose K → Find Centers → Assign Points → Recalculate Centers → Repeat


One-line exam answer:
K-Means is an unsupervised clustering algorithm that divides data into K clusters by assigning each data point to the nearest centroid and repeatedly updating the centroids.






##  Hierarchical Clustering

Hierarchical Clustering is an unsupervised learning algorithm used to group similar data points into clusters.

Unlike K-Means, it creates a hierarchy (tree) of clusters.

Simple Example

Suppose we have 5 customers:

A   B   C   D   E

The algorithm first finds similar customers and gradually creates groups:

        ┌───────────────┐
        │               │
      ┌─┴─┐           ┌─┴─┐
      A   B           C   ┌─┴─┐
                          D   E

This tree is called a Dendrogram.

Types of Hierarchical Clustering
1. Agglomerative Clustering ⭐

Bottom → Up

A   B   C   D
↓   ↓   ↓   ↓
Individual clusters
       ↓
   Merge similar
       ↓
    Bigger clusters
       ↓
    One big cluster

It starts with each data point as a separate cluster and keeps merging them.

2. Divisive Clustering

Top → Down

   One Big Cluster
         ↓
       Split
      ↙    ↘
   Group 1 Group 2
      ↓      ↓
    Split  Split

It starts with one big cluster and repeatedly splits it.

Dendrogram

A dendrogram is a tree-like diagram showing how clusters are merged or divided.

Distance
  |
  |          ┌───────────────┐
  |      ┌───┤               │
  |   ┌──┤   │               │
  | ┌─┤  │   │               │
  | A B  C   D               E
  +----------------------------→ Data

We can cut the dendrogram at a particular level to decide the number of clusters.

## DBSCAN

DBSCAN stands for Density-Based Spatial Clustering of Applications with Noise.

It is an unsupervised clustering algorithm that creates clusters based on the density of data points.

Simple Definition

DBSCAN groups points that are closely packed together and identifies isolated points as noise/outliers.

How DBSCAN Works

DBSCAN mainly uses 2 parameters:

Epsilon (ε) → maximum distance to consider points as neighbors.
MinPts → minimum number of points needed to form a dense region.

Identify dense regions

Create clusters
     ↓
Identify isolated points
     ↓
Noise / Outliers
Three Important Terms

1. Core Point
A point having at least MinPts points within ε distance.

2. Border Point
A point near a core point but doesn't have enough neighbors to be a core point itself.

3. Noise Point
A point that doesn't belong to any cluster.

## Silhouette Score in Clustering

Silhouette Score is a performance metric for clustering. It tells us how well the data points are placed in their clusters.

Higher Silhouette Score = Better-defined clusters.

Simple Example

Suppose K-Means creates 3 clusters:

Cluster 1     Cluster 2     Cluster 3
 ● ● ●          ● ● ●          ● ● ●
 ● ● ●          ● ● ●          ● ● ●

Silhouette Score checks:

Are points close to their own cluster?
Are points far from other clusters?
Silhouette Score Range

The score is between -1 and +1.

Score	Meaning
Close to +1	Very good clustering
Around 0	Clusters overlap
Negative	Point may be in the wrong cluster
Formula
$$ S = \frac{b-a}{\max(a,b)} $$

Where:

a = average distance from a point to points in its own cluster
b = average distance from a point to points in the nearest other cluster
Easy Understanding
Point
 ↓
Distance within own cluster → a
Distance to nearest other cluster → b
 ↓
Compare a and b
 ↓
Silhouette Score

If:

a = 2
b = 8

then:

$$ S = \frac{8-2}{8}=0.75 $$

0.75 → Good clustering ✅

K-Means + Silhouette Score

Silhouette Score can help choose the best K:

K = 2 → Score = 0.45
K = 3 → Score = 0.72  ← Best
K = 4 → Score = 0.61
K = 5 → Score = 0.50

Choose K = 3 because it has the highest score.

🧠 Easy Memory Trick

Silhouette = Separation + Similarity

High score → points are close to their own cluster and far from other clusters.

One-line exam answer:
Silhouette Score is a clustering evaluation metric ranging from -1 to +1 that measures how well each data point fits within its own cluster compared with the nearest other cluster.
